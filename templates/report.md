```markdown
Training      deadlift 3x12 @60 kg              done

What changed

Notes
- lunch estimate edited downward (rice 150g -> 120g)
- dinner out; oil estimate is the weakest number today
```

---

## The three states

**Deficit**
| State | Meaning |
|---|---|
| `ok` | within target |
| `light` | below target — recovering, not a failure |
| `high` | above target — stated plainly, no alarm |

**Training**
| State | Meaning |
|---|---|
| `done` | session completed |
| `rest` | planned rest day |
| `skipped` | session not done. **No judgement attached.** |

---

## Rules for anyone editing this template

1. One screen. If it scrolls on a phone, cut.
2. `What changed` gets **exactly one line**.
3. No colour coding by medical threshold.
4. No motivational language.
5. Estimates stay labelled as estimates.
6. `Next session` is arithmetic, not a guess — it comes from `SKILL.md` §5.2
   (**+2.5 kg upper body, +5 kg lower body** when every prescribed rep was completed at target
   RPE). Deadlift is lower body, so 60 kg → 65 kg. The same log must give the same answer in any
   tool.
